# 服务器收编清单

这里记录所有已知云主机。它与 `hosts/` 的职责不同：`hosts/` 只接受已经审计、可由
Flake 重建的配置；本目录保存在线状态、缺失信息和收编条件，防止未验证的声明配置
覆盖正在运行的服务。

## 收编规则

一台机器只有同时满足以下条件，才能从本目录移入 `hosts/<name>/` 并加入
`nixosConfigurations`：

1. 已确认架构、启动方式、磁盘设备、分区和网络接口；
2. 已盘点服务、可变数据路径、监听端口与依赖；
3. 已将恢复所需密钥以 SOPS 密文保存，并在独立位置验证恢复；
4. 已在保留 SSH 会话的前提下完成 `nixos-rebuild test`；
5. 配置通过 `nix flake check path:/home/dot/.dotfiles/servers`。
