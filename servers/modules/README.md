# 服务器可复用模块

此目录仅定义可由多台服务器复用的 NixOS 模块；具体主机是否启用、端口、域名、SOPS
引用和数据路径，留给 `../hosts/<name>/` 组装层。

| 目录 | 职责 |
| --- | --- |
| `server/` | 所有服务器共享基线：用户、SSH、防火墙、Nix、网络、BBR |
| `services/` | 可选的应用 / 服务模块：代理、EasyTier、数据库、备份、缓存、存储等 |

新增模块前确认它不是某一台机器的特例；若只有一个主机使用且与其数据路径、域名或
云平台强绑定，应先放进该主机域目录。模块必须有标准头部、单一职责、显式 options 和
安全默认值；不要在默认值中嵌入真实凭据、主机 IP 或用户数据路径。

`services/default.nix` 和 `server/default.nix` 只作 import switchboard。新增模块只有
在被至少一个受管主机显式使用并完成验证后，才加入相应 switchboard。
