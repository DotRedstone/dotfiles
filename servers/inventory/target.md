## 优选探测入口的历史核对

2026-10-13 的只读核对确认，配置的公网 SSH 地址可连至 `target`，Nginx 运行中，
但没有 `80/443` 监听或 TLS 虚拟主机；当前主机防火墙规则也未放行这两个端口。
Conduit 与 Hopper 从各自公网连接该地址的 `80/443` 均超时。工作站网络受 TUN
影响，其本地 TCP 连接结果不用于判定公网可达性。上述证据不能区分腾讯云安全组
是否同时阻断了端口；当时也没有可用的腾讯云只读 CLI 凭据。由于 Target 不再
承担探测入口，安全组 443 不再是 v2 灰度的待办项。

当日主机无 ACME 单元或证书目录，SOPS 曾为未启用预览登记独立 DNS-01 token
和探测环境；尚未部署证书与服务。历史准备和凭据后续处理见
[代理部署数据](../proxy-deployment/README.md#target-历史探测预览已废弃)。
Cloudflare 上拟用于隔离探测的 `probe-v2-canary.dotdot.ggff.net` 尚无 DNS 记录。
锁定 Worker 源码曾在 Flake 中预接入 Target 的默认关闭模块；
`codex/target-probe-dryrun` 保留为未合并、未部署的历史预览。
关闭状态的求值未生成探测服务，也未改变防火墙或 Nginx。源码求值与 SSH 核对
不证明公网 HTTPS 探测可用。

## 退役前必须重新盘点

- 硬件、磁盘、启动方式和云平台网络；
- 正在运行的服务、端口、服务数据和外部依赖；
- 是否属于国内 EasyTier 网络、是否承载反代或代理入口；
- 需要进入 SOPS 的密钥，以及恢复测试所需的最小数据集。

## 后续规则

退役前如需维护现有服务，仍须核对其持久数据和备份恢复状态；不要把反代运行时
缓存误当成需要备份的数据。退役执行步骤须另行审查，不由探测预览触发。
